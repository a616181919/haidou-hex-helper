# ⚔️ 海克斯大乱斗小助手

英雄联盟【海克斯大乱斗】模式助手 — **全免费 · 无广告 · 无会员**

## ✨ 功能
- **英雄推荐**: 173位英雄, 按大乱斗胜率排序, 支持中文名/别名搜索
- **海克斯推荐**: 每英雄胜率+选取率排序, 含效果描述与稀有度(棱彩/黄金/白银)
- **海克斯图鉴**: 268个海克斯全库检索, 按稀有度筛选
- **版本改动**: 英雄/海克斯逐版本改动记录

## 🔄 数据更新
- 内置快照: 2026-10-24 (173英雄 / 268海克斯 / 196装备)
- 在线数据: 打开页面自动尝试拉取最新胜率, 失败时回退本地快照

## 🚀 部署
纯静态站点(原生 ES Module, 零构建零依赖), 托管于 GitHub Pages。

本地预览:
```bash
npx serve .        # 或任何静态服务器
```
